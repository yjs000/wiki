# yjs000 Wiki

공식 자료와 실제 경험을 연결해 학습 과정, 기술 판단, 설계 관점의 변화를 기록하는 공개 기술 위키입니다.

## 전체 카테고리

- [학습계획](docs/learning-plans/README.md) — 학습목표를 흡수하고 주제별 계획과 통과 조건을 관리합니다.
- [학습기록](docs/learning-records/README.md) — 학습계획 주제별 질문, 실험, 판정과 증거를 보존합니다.
- [읽을거리](docs/readings/README.md) — 주제별 기술 아티클을 모읍니다.
- [관련 프로젝트](docs/projects/README.md) — Wiki와 직접 연결된 실제 프로젝트를 설명합니다.

각 구조 변경은 이 루트 README와 영향받는 모든 하위 README를 같은 커밋에서 갱신합니다.
