# RAG 학습증거 통합 설계

|---|---|---|---|

2026-07-22 개념 게이트의 학습자 원문과 정정 기준을 보존하면서, 2026-08-11 law-rag 1블록 점검을 이 주제의 현재 통합 기록으로 만든다.

## 목표와 문서 역할

- **통합본:** `2026-08-11-law-rag-roadmap-block-1-review.md`를 현재 판단, 초기 원문, 정정, 구현 증거, 다음 검증을 한 번에 읽는 기준 문서로 유지한다.
- **원문 안내본:** `2026-07-22-rag-pipeline-concept-gate.md`는 삭제하지 않는다. 원래 학습자 답변과 초기 피드백이 통합본에 포함됐음을 알리고 통합본으로 연결한다.
- **보존 원칙:** 학습자가 직접 작성한 질문·답변은 수정하거나 요약하지 않는다. 이 내용은 통합본에 원문 블록으로 옮긴다.

## 통합 방식

1. 통합본에 초기 개념 게이트의 맥락, 학습자 원문, 핵심 정정을 `초기 개념 게이트: 원문과 정정` 절로 추가한다.
2. 중복되는 설명은 최신 pipeline 결정 절과 연결하되, 초기 설명을 최신 판단으로 덮어쓰지 않는다.
3. 통합본의 참고 자료에서 7월 문서를 `통합 전 원본`으로 표시한다.
4. 7월 문서는 제목·설명·본문을 통합 안내로 갱신하고, 독자가 통합본과 원문 보존 원칙을 즉시 알 수 있게 한다.

## 제외 범위

- law-rag 코드, 로드맵 요구사항, 실제 구현 상태는 변경하지 않는다.
- 통합 과정에서 이전 학습이 완료됐다고 재판정하지 않는다. 기존의 `부분 충족` 판정을 유지한다.

## 검증

- 두 문서의 학습자 원문이 통합본에 빠짐없이 존재하는지 문자열 검색으로 확인한다.
- Markdown 링크, 목차, front matter 및 `git diff --check`를 확인한다.
- 변경 diff를 검토해 7월 문서가 삭제되지 않고 통합 안내로 남았는지 확인한다.
