# 학습 계획과 학습증거 계층화 설계

| 작성자 | 게시·수정일 | 읽는 시간 | 태그 |

| yjs000 | 2026-08-12 | 약 3분 | Study Roadmap · Learning Evidence · Documentation |

새 학습 목표와 관련 아티클이 들어올 때마다 문서를 늘어놓지 않고, README에서 시작하는 하나의 학습 주제 계층 안에 계획과 증거를 병합한다.

## 기준 계층

```text
README 카테고리
→ 학습 로드맵
  → 학습 주제
    → 세부 주제
      → 학습증거와 관련 아티클
```

- **README 카테고리:** 독자와 에이전트가 새 목표의 첫 소속을 찾는 최상위 인덱스다.
- **학습 로드맵:** 목표의 순서, 통과 조건, 주제와 세부 주제를 가진 계획의 기준 문서다.
- **학습 주제와 세부 주제:** 계획과 증거의 병합 단위다. 같은 개념을 다른 이름으로 반복 생성하지 않는다.
- **학습증거와 관련 아티클:** 학습자 원문, 실험, 코드 읽기, 설계 판단을 세부 주제 아래에 연결한다. 아티클은 읽을거리로 유지하고, 학습자가 직접 다룬 내용은 별도 학습증거로도 연결한다.

## 자동 분류와 병합 규칙

1. `TODO.md`에 목표를 추가하거나 학습 목표가 대화에 들어오면 README의 기존 카테고리와 로드맵을 먼저 찾는다.
2. 목표의 의미가 기존 주제·세부 주제와 겹치면 그 절에 목표·달성 조건·링크를 병합한다. 새 로드맵은 어떤 기존 주제에도 속하지 않을 때만 만든다.
3. 관련 아티클, 질문, 실험, 코드 읽기가 들어오면 하나의 1차 소속 주제·세부 주제를 지정해 학습증거로 기록한다.
4. 한 자료가 여러 주제와 연결돼도 학습증거 본문은 1차 소속에 한 번만 둔다. 다른 로드맵과 아티클에서는 링크로 참조한다.
5. 같은 1차 소속·세부 주제의 증거는 기존 학습증거 문서의 해당 절에 날짜 순으로 병합한다. 학습자 원문은 이전 답을 덮어쓰거나 고치지 않는다.
6. 새 파일은 세부 주제에 기존 증거 문서가 없거나, 독립된 학습 맥락·원문·판정이 있어 분리해야 읽기 쉬울 때만 만든다.

## 기존 문서의 재분류

- **AI 시스템 → RAG 전체 경로 → 데이터 준비·검색·근거 검증:** `2026-08-11-law-rag-roadmap-block-1-review.md`를 1차 학습증거로 둔다. 7월 문서는 URL 보존 안내다.
- **에이전트 프레임워크 → LangGraph → 실행 경로 코드 읽기:** `agent-service-toolkit` 아티클을 1차 관련 아티클로 둔다. 이 자료의 질문·판정은 새 학습증거에 연결한다.
- **AI 시스템 → 작은 오픈소스 실행 경로 읽기:** 위 LangGraph 증거를 다시 복사하지 않고 참조한다. 축소 재구현 전에는 개념 설명 증거로만 판정한다.

## 변경 범위와 검증

- `AGENTS.md`에는 모든 변경에 적용되는 짧은 자동 분류·병합 트리거를 둔다.
- `docs/learning-evidence/README.md`에는 학습증거의 1차 소속, 계층 표기, 병합 규칙과 검사 항목을 둔다.
- `README.md`는 원칙을 반복하지 않고 기존 카테고리·로드맵 링크만 최상위 인덱스로 유지한다.
- 두 로드맵에는 주제별 학습증거 링크를 추가하고, LangGraph 관련 문서는 하나의 1차 소속만 가진다.
- 링크 대상, 중복 제목, 학습자 원문 보존, Markdown 형식을 검사한다.
