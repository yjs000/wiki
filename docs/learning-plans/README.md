# 학습계획

학습목표를 기존 주제에 흡수하고, `주제 → 세부 주제 → 학습기록` 순서로 연결한다. 같은 목표가 들어오면 새 계획을 만들기 전에 아래 주제와 겹치는지 확인한다.

## 현재 학습목표

1. [x] **Codex로 실제 프로젝트를 진행한다** — [law-rag](https://github.com/yjs000/law-rag)에 Codex를 활용했다.
2. [ ] **RAG 검색 시스템을 코드와 평가 결과로 설명한다** — 일반 검색, 벡터 검색, 하이브리드 검색을 같은 평가셋으로 비교한다.
3. [ ] **AI 오픈소스의 주요 실행 경로를 읽고 축소 재구현한다** — 진입점, 상태, 호출 흐름, 실패 처리를 기준으로 평가한다.
4. [ ] **GitHub Issues와 Symphony로 코딩 작업을 실행한다** — 작은 저장소에서 격리, 재시도, 상태 전이와 PR 검증을 직접 확인한다.
5. [ ] **Discord, Hermes, Symphony를 역할이 겹치지 않게 연결한다** — Hermes는 요청·판단·결과 설명을, Symphony는 Issue dispatch와 Codex 실행을 담당한다.
6. [ ] **에이전트 프레임워크를 학습 순서대로 익힌다** — Function Calling → LangChain Agent → LangGraph → Agentic RAG 직접 구현 → Multi-Agent → 프레임워크 비교.

- [에이전트 프레임워크](agent-framework/README.md) — Function Calling부터 LangGraph, Agentic RAG, Multi-Agent와 프레임워크 비교
